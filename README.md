# Nitesh Negi — Digital Marketing Portfolio

A responsive, single-page portfolio website built with HTML, CSS and a small amount of JavaScript. It uses a premium dark + emerald green theme and includes the supplied profile photo.

## Files
- `index.html` — the complete website
- `assets/nitesh-negi.jpg` — profile photo used in the hero card

## Publish free with GitHub Pages

1. Sign in to GitHub: https://github.com/nitesh-negi-digitalmarketing
2. Create a **Public** repository named exactly: `nitesh-negi-digitalmarketing.github.io`
3. Open the repository and choose **Add file → Upload files**.
4. Upload `index.html` and the complete `assets` folder (keep the folder name `assets`). You can also upload this README.
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/ (root)`, then click **Save**.
9. Wait a few minutes and open: https://nitesh-negi-digitalmarketing.github.io/

## Updating the website
Edit `index.html` in GitHub (pencil icon) or replace it with an updated file. When changing the profile image, keep the path `assets/nitesh-negi.jpg` or update the image path in `index.html`.

## Notes
- No paid domain is required. GitHub Pages provides a free `github.io` address.
- The website does not include analytics or tracking scripts.
- Review all project descriptions and certification dates before publishing. Keep claims aligned with the work you personally completed.
