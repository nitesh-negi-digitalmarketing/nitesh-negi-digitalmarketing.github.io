
# Nitesh Negi — Digital Marketing Portfolio

A responsive, single-page portfolio website built with HTML, CSS and JavaScript. It features a premium dark and emerald green theme, responsive layouts and a profile photo.

## Files

- `index.html` — Complete portfolio website
- `nitesh-negi.jpg` — Profile photo used in the hero section

## Profile Image

The profile photo is stored in the root directory of this GitHub repository and loaded directly using its raw GitHub URL:

https://raw.githubusercontent.com/nitesh-negi-digitalmarketing/nitesh-negi-digitalmarketing.github.io/main/nitesh-negi.jpg

## Publish with GitHub Pages

1. Open the repository:
   https://github.com/nitesh-negi-digitalmarketing/nitesh-negi-digitalmarketing.github.io
2. Upload `index.html` and `nitesh-negi.jpg` to the root directory.
3. Click Commit changes.
4. Open Settings → Pages.
5. Select Deploy from a branch.
6. Select `main` and `/ (root)`.
7. Click Save.

Website: https://nitesh-negi-digitalmarketing.github.io/

## Updating the Website

Edit `index.html` using the GitHub pencil icon. Keep the profile image URL updated if the image file is moved or renamed.
